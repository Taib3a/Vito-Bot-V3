# STARX — استوديو الصور بالذكاء الاصطناعي

موقع عربي (RTL) لتوليد الصور وتعديلها، بواجهة داكنة وأدوات جاهزة:

- توليد الصور من وصف نصي
- استخراج قناع الصورة
- تغيير الخلفية
- تحسين الإضاءة
- تحسين الظلال
- إزالة تجاعيد الملابس
- تعديل المشهد

## التشغيل

```bash
node starx/server.js          # http://localhost:3000
PORT=8080 node starx/server.js
```

لا يحتاج أي حزم — Node 18+ فقط.

## الوضعان

| الوضع | متى | ماذا يحدث |
|---|---|---|
| تجريبي | بلا مفتاح API | يولّد صورة SVG تجريبية محلياً لتجربة الواجهة كاملة |
| متصل | مع `IMAGE_API_KEY` | يرسل الطلب لمزوّد متوافق مع OpenAI Images |

## متغيّرات البيئة

```bash
IMAGE_API_KEY=sk-...                                  # مطلوب للوضع المتصل
IMAGE_MODEL=gpt-image-1                               # أو أي موديل يدعمه مزوّدك
IMAGE_API_URL=https://api.openai.com/v1/images/generations
IMAGE_EDIT_URL=                                        # اختياري: نقطة تعديل الصور
PORT=3000
```

- أدوات الصور (خلفية/إضاءة/ظلال/تجاعيد/مشهد) تحتاج `IMAGE_EDIT_URL` لتعديل الصورة فعلياً؛
  بدونها تعمل في الوضع التجريبي.
- المزوّد يجب أن يقبل JSON ويعيد `{data:[{b64_json|url}]}`.

## البنية

```
starx/
├── index.html   الواجهة
├── styles.css   التنسيق (RTL، داكن، متجاوب)
├── app.js       المنطق: الأدوات، الرفع، التوليد، السجل المحلي
└── server.js    سيرفر Node: ملفات ثابتة + /api/generate + /api/health
```

السجل يُحفظ في `localStorage` (آخر 24 صورة) ويمكن مسحه بزر «مسح الكل».
