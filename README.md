## 🚀 النشر على الخادم

<div align="center">

<a href="https://dash.server-veto.com">
<img src="https://img.shields.io/badge/🚀_Deploy_on_Server_Veto-اشترك_الآن-25D366?style=for-the-badge&logo=server&logoColor=white" alt="Deploy on Server Veto" height="45"/>
</a>

<br><br>

</div>

بعد الدخول إلى لوحة التحكم في **Server Veto** (Pterodactyl)، اتبع الخطوات التالية:

**١. تحميل البوت** — افتح سطر الأوامر في لوحة التحكم واكتب أمر `git clone` لتحميل المشروع، ثم انتقل إلى مجلد المشروع.

```bash
git clone https://github.com/taib/bot-vito-v3.git
cd bot-vito-v3
```

**٢. تثبيت المكتبات** — اكتب `npm install` لتثبيت جميع المكتبات اللازمة. انتظر حتى انتهاء التثبيت بنجاح.

```bash
npm install
```

**٣. تشغيل البوت** — اكتب `npm start` لتشغيل البوت. سيبدأ البوت بالعمل فوراً.

```bash
npm start
```

**٤. ربط البوت بحساب واتساب** — عند التشغيل، اختر طريقة الربط:

| الخيار | الطريقة | الشرح |
|:---:|:---|:---|
| `1` | Pairing Code | أدخل رقم الهاتف مع رمز الدولة، ثم أدخل الرمز في واتساب |
| `2` | QR Code | امسح رمز QR بكاميرا هاتفك من الأجهزة المرتبطة |

> 💡 بعد الربط الأول، يحفظ البوت الجلسة تلقائياً ولن يطلب إعادة الربط.
