## 🚀 النشر على الخادم (طريقة يدوية بالكامل)

<div align="center">

<a href="https://dash.server-veto.com">
<img src="https://img.shields.io/badge/🚀_Deploy_on_Server_Veto-اشترك_الآن-25D366?style=for-the-badge&logo=server&logoColor=white" alt="Deploy on Server Veto" height="45"/>
</a>

<br><br>

</div>

إذا كنت مبتدئاً ولا تعرف كيف تستخدم سطر الأوامر، يمكنك اتباع هذه الخطوات البسيطة:

1. **تحميل المشروع:** اضغط على الزر الأخضر `Code` في أعلى صفحة GitHub هذه، واختر **Download ZIP** لتحميل المشروع كملف مضغوط إلى هاتفك.
2. **التسجيل في الاستضافة:** اذهب إلى لوحة تحكم **Server Veto** (https://dash.server-veto.com)، وسجل حساباً جديداً (يمكنك شراء سيرفر أو الحصول على مساحة من المطور).
3. **رفع الملفات:** من داخل لوحة التحكم، اذهب إلى قسم **File Manager** (مدير الملفات).
4. **فك الضغط:** قم برفع ملف الـ ZIP الذي حملته، ثم اضغط عليه بزر الماوس الأيمن واختر **Extract** (فك الضغط).
5. **التشغيل:** اذهب إلى قسم **Console** في لوحة التحكم، واضغط على زر التشغيل (Start). سيقوم السيرفر تلقائياً بتثبيت المكتبات وتشغيل البوت (قد يستغرق دقيقة).
6. **الربط:** راقب شاشة الكونسول، وعندما يطلب منك الاختيار، اكتب `1` لكود الاقتران أو `2` لمسح الباركود.

> 💡 **ملاحظة:** بعد الربط الأول، يحفظ البوت الجلسة تلقائياً ولن يطلب إعادة الربط مرة أخرى.

```
Vito-Bot-V3/
├── index.js                  # نقطة الدخول (اختيار طريقة الربط)
├── database/
│   └── db.js                 # قاعدة بيانات node:sqlite
├── scripts/
│   ├── check.js              # فحص صياغة الملفات (npm run build)
│   └── smoke.js              # اختبار عدم الانهيار (npm test)
├── الاضافات/                  # الوحدات الأساسية
│   ├── النظام.js             # الاتصال بواتساب وربط الأحداث
│   ├── الجلسة.js             # تخزين الجلسة في ملف واحد (auth.db)
│   ├── الادخال.js            # موجّه أسئلة الكونسول (يخزّن الأسطر)
│   ├── المعالج.js            # معالجة الرسائل وتوجيه الأوامر
│   ├── المحمل.js             # تحميل الأوامر من مجلد الاوامر
│   ├── محمل-المضاد.js        # تحميل الميزات المضادة
│   ├── معلومات-الرسالة.js    # دوال قراءة بيانات الرسالة
│   ├── ادوات-المجموعة.js     # دوال مساعدة (مشرفين، أهداف)
│   ├── القاعدة.js            # واجهة قاعدة البيانات
│   ├── الكونسل.js            # واجهة الطرفية والسجلات
│   ├── الاعدادات.js          # الإعدادات العامة
│   └── مضاد/                 # الميزات المضادة (روابط، بوتات، ترحيب...)
└── الاوامر/                   # جميع الأوامر (تُحمَّل تلقائياً)
    ├── ping.js  menu.js  alive.js
    ├── مجموعة/               # أوامر إدارة المجموعة
    └── تنصيب/                # أوامر البوتات الفرعية
```

## 🔌 اختبار الاتصال

تحقّق سريع من أن المشروع سليم قبل التشغيل:

```
npm run build     # فحص صياغة كل ملفات المصدر تلقائياً
npm test          # اختبار عدم الانهيار (الأوامر + قاعدة البيانات + المعالج)
```

- `npm run build` يفحص `index.js` وكل ملفات `الاضافات/` و`الاوامر/` تلقائياً، لذلك
  يمكنك إضافة أوامر جديدة دون تعديل `package.json`.
- `npm test` يشغّل قاعدة بيانات مؤقتة معزولة ويطبع عدد الأوامر المحمّلة، ثم يمرّر
  رسالة تجريبية عبر المعالج للتأكد من عدم وجود أي انهيار.

> ملاحظة: واتساب يغلق السوكيت غير المسجَّل بعد أجزاء من الثانية من انتهاء
> المصافحة، لذلك يُرسل طلب كود الربط فوراً بعد فتح السوكيت (بدون تأخير).
