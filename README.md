## 🚀 DEPLOY ON VPS

<div align="center">

### النشر على منصة Server Veto (Pterodactyl)

</div>

قم بنشر البوت على خادم VPS عبر منصة **Server Veto** باستخدام لوحة Pterodactyl باتباع الخطوات التالية:

**١. تحميل البوت**
```bash
git clone https://github.com/taib/bot-vito-v3.git
cd bot-vito-v3
```

**٢. تثبيت المكتبات**
```bash
npm install
```

**٣. تشغيل البوت**
```bash
npm start
```

**٤. ربط البوت بحساب واتساب**

| الخيار | الطريقة | الشرح |
|:---:|:---|:---|
| `1` | Pairing Code | أدخل رقم الهاتف مع رمز الدولة (مثال: 967777123456) ثم أدخل الرمز الظاهر في واتساب |
| `2` | QR Code | امسح رمز QR الظاهر في الشاشة بكاميرا هاتفك من خلال الأجهزة المرتبطة |

> 💡 بعد الربط الأول، يحفظ البوت الجلسة تلقائياً ولن يحتاج لإعادة الربط عند كل تشغيل.

## 📋 الأوامر الأساسية

<div align="center">

| الأمر | الوظيفة |
|:---|:---|
| `.ping` | اختبار سرعة استجابة البوت |
| `.menu` | عرض قائمة جميع الأوامر |
| `.alive` | التحقق من حالة البوت |
| `.تفعيل` | تفعيل البوت في المجموعة |
| `.تعطيل` | إيقاف البوت في المجموعة |
| `.طرد @الشخص` | طرد عضو من المجموعة |
| `.ترقية @الشخص` | ترقية عضو إلى مشرف |
| `.خفض @الشخص` | خفض مشرف إلى عضو |
| `.كتم` | كتم المجموعة |
| `.فك-كتم` | إلغاء كتم المجموعة |
| `.تشغيل [ميزة]` | تشغيل ميزة معينة |
| `.ايقاف [ميزة]` | إيقاف ميزة معينة |
| `.تنصيب [رقم]` | تنصيب بوت فرعي جديد |
